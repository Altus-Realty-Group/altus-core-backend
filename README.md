# Altus Core Backend

This repository is the main backend runtime repository for the Altus Core / Enterprise Asset Master system.

It contains backend code, Azure Functions, asset master backend services, and backend/auth documentation used to support Altus platform runtime behavior.

This repository is distinct from `altus-core-ops`.

Use this repository for:

- Azure Functions backend work
- Enterprise Asset Master backend services
- Backend API/runtime code
- Auth/backend evidence documentation
- Supabase-backed backend integration documentation

Do not use this repository for:

- General Codex/autonomy scaffold templates unless they directly support this backend repo
- Cross-platform agent-governance boilerplate that belongs in `altus-core-ops`

Auth documentation location:

- `docs/auth/`

Code repo for the Enterprise Asset Master + Azure Functions.
